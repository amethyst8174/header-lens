Why it's safe to paste real headers here
  • Processed on your device. Parsing and scoring run as JavaScript in this tab. There is no server behind this page.
  • The browser blocks outbound traffic. A Content Security Policy forbids this page from sending requests or submitting forms, so data cannot leave even by mistake.
  • Nothing persists. No cookies, local storage or caching. Leaving or reloading the page wipes everything.
  • No third parties. Fonts, scripts and images are served from this repository. No analytics, no trackers, no CDNs.
  • Verify it yourself. Open DevTools: the Network tab stays empty after you paste, and Application storage is blank. The full source is on GitHub.
